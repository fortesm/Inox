# utils/inox-lsp/

A language server (Language Server Protocol) for Inox: diagnostics as you
type, go to definition, hover with types and contracts, completion of names
and module members, the public surface of a module (`inox interface`).
Planned; it reuses the compiler's library, and serves every editor in
`contrib/`.
