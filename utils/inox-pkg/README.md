# utils/inox-pkg/

The package tool (constitution FUTURE, decided by Marcelo Fortes on
2026-10-29): finds and downloads Inox packages, a project or modules packed
for the community to reuse, into a folder that joins the module search
order of CANON-3 (after the entry directory and `--path`). Planned; its
design (package format, registry, versions, lock file) needs approval
first.
