# contrib/docker/

A container image with Inox ready to use: the release package, clang and
the standard library (`Dockerfile`), for CI, for trying Inox without
installing it, and for reproducible builds. Expected tags follow the
versions (`inox:0.4.0`, `inox:latest`).
