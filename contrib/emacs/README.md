# contrib/emacs/

An Emacs major mode for Inox: `inox-mode.el`, with syntax highlighting,
indentation, comments (`==`) and the association with `*.inox` files; later
an Eglot or lsp-mode setup for the language server (`utils/inox-lsp/`).
